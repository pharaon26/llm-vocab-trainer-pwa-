# LLM Vocab Trainer

Мобильное PWA для усвоения профессиональной английской лексики (сначала ИТ и информационная безопасность): интервальное повторение, которое учитывает тип ошибки, и задания, которые генерирует и проверяет языковая модель.

[English version](README.md) · [Журнал решений](DECISIONS.md) · [Подробное руководство](docs/GUIDE.ru.md)

![Задание на телефоне](docs/screenshots/phone-light-task.png)

Остальные скриншоты (светлая и тёмная темы, телефон и ПК, кабинет преподавателя) - в [английском README](README.md).

## Что умеет

- Интервальное повторение (модификация SM-2): интервал и коэффициент легкости после ошибки меняются по-разному для четырёх типов (форма, значение, употребление, словосочетание), тип ошибки определяет следующее задание.
- Задания генерирует LLM и проверяет до показа студенту: правила, вторая проверка на однозначность, повторы, банк заданий и запасное алгоритмическое задание.
- Открытые ответы классифицируются: опечатки без LLM, объяснения и предложения - моделью.
- Карточки меняют только люди, модель их не изменяет.
- Студент добавляет свои слова: черновик из словаря и модели, источник каждого поля подписан, подтверждает студент.
- Преподаватель и студент связываются по взаимному согласию (приглашение или заявка по нику), есть группы, свои карточки и наборы преподавателя, сводки и агрегированная аналитика без отдельных ответов.
- Установка как приложение, светлая и тёмная темы.

## Быстрый старт

Нужен Docker.

```bash
cp .env.example .env        # задайте POSTGRES_PASSWORD
docker compose up --build   # PostgreSQL + приложение, миграции применяются при старте
docker compose exec app python -m app.seed          # 24 стартовые карточки
docker compose exec app python -m app.verify_seed   # пометить проверенными после просмотра data/cards.json
docker compose exec app python -m app.create_admin ВАШ_НИК
docker compose exec app python -m app.seed --decks   # по желанию: 8 тематических наборов (200 карточек), загружаются непроверенными
```

Приложение: <http://localhost:8000>, кабинет преподавателя: `/teacher.html`. Регистрация как преподавателя - галочка «Я преподаватель».

## Тесты

```bash
docker compose up -d postgres
pip install -r requirements-dev.txt
pytest
```

Тесты идут на отдельной базе `<POSTGRES_DB>_test`, каждый тест в транзакции с откатом.

## Безопасность

Серверная сессия в cookie (`HttpOnly`, `Secure`, `SameSite=Lax`, в БД только хеш), защита от CSRF по `Origin`, Content-Security-Policy без inline и eval, пароли argon2id, ограничение неудачных входов в БД, проверка владельца во всех запросах (тесты на IDOR), в LLM уходят только термин, поля карточки и ответ студента. Подробнее - в [английском README](README.md#security) и [DECISIONS.md](DECISIONS.md).
